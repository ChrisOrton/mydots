# Flycast set up
## Basics
[install](https://github.com/flyinghead/flycast)

Flatpak (Linux ubuntu logo)

Set up Flatpak.



```
sudo apt install flatpak
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

```

Install Flycast from Flathub:

```
flatpak install -y org.flycast.Flycast

```

Run Flycast:

```

flatpak run org.flycast.Flycast

```

## Commands
To quit a game in the Flycast emulator using a keyboard, use the following default shortcut:

    ESC (Escape Key): This is the default key to exit Flycast and return to the menu or desktop.
    Alt + F4: Standard Windows shortcut to force quit the application. 

Other common methods:

    Toggle Menu (TAB): Pressing TAB often brings up the in-game emulator menu, which includes an "Exit" option.
    Windowed Mode: If in full screen, press Alt+Enter to switch to windowed mode, then click the 'X' in the top-right corner to close.
